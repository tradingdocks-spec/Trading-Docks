# Trading Docks Mobile Alpha 0.4 — First Five Seconds

## What changed

- Added a cinematic Dock Core launch sequence.
- Reworked the hero around the proprietary “collection pulse” identity.
- Replaced the generic bar chart with an animated pulse-node visualization.
- Added a daily collection movement moment and market signal card.
- Introduced tactile quick-action chips for Scan, Signals, and Sell.
- Added a breathing magnetic CTA with haptic feedback.
- Reduced explanatory copy and strengthened visual hierarchy.
- Preserved Expo SDK 54 and the existing dependency set.

## Product direction

This release is intentionally focused on first impression, memorability, motion, and collector emotion rather than adding new back-end features.
