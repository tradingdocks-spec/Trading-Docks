# Trading Docks Admin Command Center

Added a protected, responsive administrative workspace for web and mobile:

- Role-aware Command Center entry in Profile
- Owner, Admin, Support, and Analyst roles
- Platform overview metrics
- User directory and account-access controls
- Subscription overview
- System-health readiness checks
- Immutable audit-log viewer
- Plan-entitlement matrix
- Feature-flag foundation
- Supabase RLS migration and secure RPC functions
- One-time Owner bootstrap instructions

Administrative roles remain separate from customer subscription plans. No service-role key is included in the client.
