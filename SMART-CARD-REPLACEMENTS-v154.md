# Smart Card Replacements — v154

- Moves the table-view card preview below and closer to the pointer.
- Connects the Card Inspector's Find Replacement button.
- Identifies each selected card's primary deck-building role.
- Suggests functionally similar cards using live Scryfall card data.
- Filters every recommendation for the deck's selected format.
- Respects Commander and Pauper Commander color identity.
- Ranks alternatives by role, card type, and mana-curve fit.
- Shows the reason, fit score, mana value, and price for each option.
- Replaces one copy without disturbing the rest of the deck.
- Uses the existing Deck Vault account save flow.

No Supabase migration is required.
