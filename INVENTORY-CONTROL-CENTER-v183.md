# Inventory Control Center v183

This release turns the Inventory dashboard into a working control center.

## Included

- Global Master Inventory view across every physical location
- Search, filters, sorting, pagination, card-art mode, and bulk movement controls
- Inventory detail panel with current physical location and direct relocation
- Guided Put-Away queue with progress totals, source history, bulk filing, and binder-pocket placement
- Clickable inventory action queue for put-away, listing, pricing, listing errors, allocation, and missing-location work
- Sales-channel cards that filter inventory operations
- Collapsible Inventory introduction that remembers the returning user's preference
- Existing PSA Slab Vault, TCGplayer order import, and persistent Connected status preserved

No new Supabase migration is required.
