# Trading Docks Mobile Alpha 0.2

Collector-first Expo SDK 54 foundation.

## Start
1. Copy your existing `.env` into this folder.
2. Run `npm install`.
3. Run `npx expo-doctor`.
4. Run `npx expo start --clear`.

This alpha includes premium onboarding, Supabase email authentication, collector dashboard, collection, scanner concept, seller workspace, and profile.
