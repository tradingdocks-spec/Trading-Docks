# Trading Docks Mobile — Alpha 0.3

## Project Docklight

This release replaces the default Expo experience with a collector-first launch and preview dashboard.

### Included
- Proprietary Docklight visual language
- Animated ambient background and floating card silhouettes
- Animated collection-pulse visualization
- Haptic primary action
- Collector and seller positioning
- Interactive preview dashboard
- Expo SDK 54 dependency set preserved from the known-good mobile project

### Install
1. Back up the current `mobile` folder.
2. Extract this ZIP into the `Trading-Docks` repository so the resulting folder is `Trading-Docks/mobile`.
3. Restore `mobile/.env` from your backup.
4. Run `npm install` and `npx expo start --clear`.

The portfolio values and signals are demonstration data in this alpha release.
