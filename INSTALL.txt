TRADING DOCKS — ADMIN MEMBERSHIP EDITOR v62

This patch adds a secure membership selector to:
Admin Control Center > Users

INSTALLATION

1. Copy the included src and supabase folders into the root of your current
   Trading Docks project. Allow the matching files to be replaced.

2. In Supabase, open SQL Editor and run:
   supabase/migrations/202607280001_admin_membership_overrides.sql

3. Redeploy the project.

USAGE

Open Admin Control Center > Users. Under Access control, choose:

- Follow billing
- Grant Free
- Grant Collector
- Grant Seller
- Grant Business

The selected level takes effect for that account without changing its Stripe
subscription or charging the user. Choose Follow billing to remove the manual
override and return the account to its normal subscription/default access.

SECURITY

- Only the permanent Trading Docks owner can change memberships.
- The owner account remains permanently protected as Business.
- Users can read only their own membership override.
- Every plan value is validated by the database function.
