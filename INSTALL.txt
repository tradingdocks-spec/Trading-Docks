INSTALLATION

1. Copy the included src and supabase folders into the root of the current
   Trading Docks project. Allow the matching MarketplaceWorkspace file to be
   replaced.

2. In Supabase SQL Editor, run the complete file:
   supabase/migrations/202607280002_marketplace_connector_foundation.sql

3. Confirm Supabase reports Success.

4. Redeploy Trading Docks and hard-refresh the Marketplace page.

IMPORTANT EMAIL NOTE

This release builds the email-tracking interface and safe architecture, but it
does not silently access any mailbox. A later connector release must complete
one of these authorized delivery methods:

- Gmail OAuth with restricted/read-only message access
- Microsoft/Outlook OAuth with restricted message access
- An inbound email provider and verified Trading Docks forwarding domain

Marketplace passwords should never be requested or stored.
