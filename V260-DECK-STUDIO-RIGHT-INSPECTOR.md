# Trading Docks v260 — Deck Studio right-inspector redesign

- Removed the Text-view floating card tooltip completely.
- Text-view rows now update the right-side Live Inspector on hover and focus.
- Removed independent scrolling and sticky behavior from the left Commander /
  Deck Explorer rail.
- Removed nested scrolling from the right rail while preserving a pinned
  inspector on large screens.
- Improved selected-row feedback, command-bar depth, canvas hierarchy, search
  language, and drop-zone copy.
- Renamed the full table workspace to Deck Canvas.
- Preserved external drops, autosave, digital trash, Undo, card replacement,
  and inventory protection.

No Supabase migration is required.
