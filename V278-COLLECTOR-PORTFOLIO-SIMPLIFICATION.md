# V278 — Collector Portfolio Simplification

The Collector Portfolio overview was rebuilt around the collection itself.

## Updated experience

- Replaced the oversized profile hero with a compact identity and metrics bar.
- Reduced navigation to Overview, Binders, Showcase, Trades, and Settings.
- Removed the decorative value chart and repetitive activity feed.
- Removed the duplicate oversized featured-binder presentation.
- Made binders the primary above-the-fold interaction.
- Added compact binder cards with real card artwork, value, card count, and page count.
- Consolidated sharing and binder creation into contextual actions.
- Kept recently added cards visible in a compact strip.
- Added a small collection-health summary for high-signal metrics.
- Preserved the existing portfolio, binder, trade, sharing, and settings behavior.
