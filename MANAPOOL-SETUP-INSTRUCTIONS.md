# Mana Pool setup in Trading Docks

1. Open https://manapool.com/seller/integrations/manapool-api
2. Sign in to the Mana Pool seller account.
3. Generate or copy the seller API key.
4. Open Trading Docks → Marketplaces → Mana Pool → Start setup.
5. Select Official API.
6. Paste the key into **Mana Pool seller API key**.
7. Save credentials.
8. Begin in read-only mode before enabling automated writes.

The key uses the existing encrypted marketplace credential storage and should never be added to GitHub or exposed in client-side code.
