# Deck Vault Condensed Views — v137

This release makes deck presentation consistent and reduces toolbar clutter.

- Duplicate imports of the same named card are combined within their deck
  section, even when they came from different printings.
- Quantities and total deck value are preserved when duplicate rows combine.
- Adding another printing of an existing card increases the existing named
  card's quantity instead of creating a second row.
- Text, grid, stack, column, condensed, and showcase/export views now receive
  the same normalized card list.
- A new Condensed view shows compact type sections with quantity, card name,
  mana identity, and total line value.
- The six individual view buttons are now organized under one polished View
  menu, with the active view visible in the control.

Commander, main deck, sideboard, and maybeboard copies remain separate so deck
structure is not lost.
