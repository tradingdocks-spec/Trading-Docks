# Trading Docks Deck Vault Poster Stats — v122

The full-deck social poster now includes:

- Deck name
- Format and commander
- Total card count
- Current deck market value
- Average mana value (excluding lands)
- Creature, instant/sorcery, and land counts
- Five-color card distribution
- Mana curve from zero through seven-plus
- A Deck Stats switch in the showcase studio

The statistics and price are calculated from the current saved deck whenever the
poster is previewed or exported. No database migration or environment variable
is required.
