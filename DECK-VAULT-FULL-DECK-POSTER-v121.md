# Deck Vault Full-Deck Poster v121

The Trading Docks Showcase Studio now creates a true full-deck poster.

- Includes every card in the deck rather than eight featured cards.
- Groups cards by Commander, Planeswalker, Creature, Artifact, Enchantment,
  Instant, Sorcery, Battle, Land, Sideboard, and Considering.
- Displays duplicate quantities as stacked-card quantity badges.
- Dynamically scales card columns to the selected Instagram portrait, square,
  or Story canvas.
- Uses a branded placeholder when one card image cannot load so the remaining
  deck still exports.
- Keeps Trading Docks Deck Vault branding and the optional public deck link on
  every exported PNG.

No Supabase migration or environment-variable change is required.
