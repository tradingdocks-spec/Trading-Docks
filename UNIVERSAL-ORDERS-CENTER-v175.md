# Universal Orders Center v175

## Included

- One professional order workspace for eBay and future TCGplayer, Shopify, CSV, and POS sources
- Live search, channel filtering, normalized status views, item counts, and expandable order details
- Gross sales, realized profit, units sold, and unmatched-item attention metrics
- Marketplace fees, shipping cost, cost of goods, refunds, tracking, and generated net profit fields
- Bulk fulfillment status updates and filtered CSV export
- Accurate empty and filtered states without demo orders
- A normalized, account-isolated database foundation for future automated inventory deductions

## Deployment

Run `00_UNIVERSAL_ORDERS_CENTER_RUN_IN_SUPABASE.sql` once in Supabase SQL Editor, then deploy the application.
