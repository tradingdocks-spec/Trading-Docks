TRADING DOCKS — FINAL MARKET IMAGE FIX

The uploaded project imported components through a lowercase path while the
actual folder was named Landing. On Windows this can silently resolve old or
duplicate files. This package:

1. Replaces both:
   src/components/Landing/MarketSection.tsx
   src/components/landing/MarketSection.tsx

2. Changes src/app/page.tsx to explicitly import:
   @/components/Landing/MarketSection

3. Removes stale MARKET_ITEMS image URLs from landing-data.ts.

4. Uses Scryfall's official collector image endpoint directly:
   https://api.scryfall.com/cards/{set}/{collector}?format=image&version=small

5. Adds an image fallback so a broken browser-image icon can no longer appear.

INSTALL
- Replace the full project with this ZIP, or copy the src and next.config.ts
  files into the actual project root.
- Delete any duplicate MarketSection.tsx files outside src.
- Stop the server.
- Delete .next.
- Restart npm run dev.

Then use Find in Files for:
  cards.scryfall.io/small/front

There should be no active homepage reference to those stale UUID URLs.
