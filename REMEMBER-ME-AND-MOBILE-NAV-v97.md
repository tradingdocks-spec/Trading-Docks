# Remember Me and mobile navigation v97

## Sign-in

- Adds a real **Remember me on this device** checkbox.
- Remembers and restores the email address on the same browser.
- Keeps the Supabase authentication cookies persistent when selected.
- Uses session-only authentication cookies when the option is cleared.
- Removes the locally remembered email when the option is cleared.
- Leaves passwords entirely under the browser/password manager's control.

## Mobile bottom bar

- Every destination uses the same fixed icon canvas.
- Every icon uses the same dimensions and stroke weight.
- Label sizing, alignment, touch targets, active styling, and navigation speed
  from v96 are preserved.
