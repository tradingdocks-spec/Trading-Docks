# Global Card Search v33

The top navigation search is now a working card locator available from every
dashboard page.

## Included

- Search by card name, set, collector number, condition, or location
- Keyboard shortcut: Ctrl+K on Windows or Command+K on macOS
- Consolidated totals for matching copies and tracked value
- Individual placement rows for binders, binder pockets, bulk boxes, custom
  locations, the Put-Away Queue, unassigned inventory, decks, and stored
  marketplace listing metadata
- Filters for Everywhere, Inventory, Decks, and Listed
- Direct navigation back to the matching inventory or deck workspace
- Responsive modal with internal scrolling and Escape/backdrop dismissal

This is the card-first foundation for later sealed-product, event, vendor, and
site-wide entity search.
