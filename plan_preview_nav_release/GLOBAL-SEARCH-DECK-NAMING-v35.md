# Trading Docks v35

## Global search

- Increased result contrast and text size.
- Made full location rows actionable with an explicit Open Location cue.
- Separated card printing details from physical storage details.
- Clarified totals as copies across locations.
- Added sorting by relevance, card name, quantity, value, and location.
- Added typo-tolerant matching for card names and related fields.
- Added keyboard navigation with Arrow Up, Arrow Down, Enter, and Escape.
- Added a larger card preview when hovering over artwork.
- Improved no-results guidance with Inventory and Scryfall actions.
- Added a scalable More control for future sealed, vendor, event, order, and task search.

## Deck Vault

- Deck names remain editable during import and creation.
- Added a Rename action to every saved deck card.
- Added inline deck-name editing inside an opened deck.
- Renamed decks persist to the account-specific deck record.
- Updated names automatically appear in Deck Vault and global search.
