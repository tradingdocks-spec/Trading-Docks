# Trading Docks v207 — Blue Brand System

The approved Trading Docks logo palette is now carried consistently through the
main customer-facing product surfaces.

## Updated
- Landing page
- Sign-in page
- Sign-up page
- Onboarding
- Dashboard shell, navigation, and home dashboard
- Shared brand components
- Route transition and browser-selection styling

## Color system
- Electric Blue: `#3B82F6` — primary actions, focus states, active navigation
- Deep Blue: `#2563EB` — button depth, borders, shadows
- Cyan: `#22D3EE` — secondary highlights and gradient endpoints
- Deep Navy: `#07121F` — branded surfaces
- Midnight: `#0F172A` — secondary surfaces
- White: `#FFFFFF` — high-emphasis typography

Status colors such as green, amber, and red were intentionally preserved because
they communicate success, warnings, and errors rather than brand identity.
