NEXT.JS APP ROUTER INSTALL
1. Copy everything inside public/ into your project's public/ folder.
2. Copy src/app/favicon.ico, src/app/icon.png, and src/app/apple-icon.png into your project's src/app/ folder.
3. Merge the contents of layout-metadata-snippet.ts into src/app/layout.tsx.
4. Deploy to Vercel.
5. Hard refresh the browser with Ctrl+Shift+R or test in Incognito.
