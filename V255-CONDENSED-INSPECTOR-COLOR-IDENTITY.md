# Trading Docks v255 — Condensed Inspector and Color Identity

## Condensed mode

- Hovering or focusing a card row now updates the existing right-side Card Inspector.
- The detached floating hover card has been removed from condensed mode.
- Clicking a card still selects it normally.
- Keyboard focus updates the inspector for accessibility.

## Color identity

- Added a dedicated compact color-identity component.
- Consistent symbol sizing.
- Colorless fallback uses the colorless symbol.
- Card names no longer collapse into mana symbols.
- Commander and condensed rows share the same visual language.

No Supabase migration is required.
