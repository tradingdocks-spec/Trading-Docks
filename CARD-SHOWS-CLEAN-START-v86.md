# Card Shows clean-start update

This release removes all preloaded Card Shows examples and default business
figures from the signed-in workspace.

## Updated behavior

- No example shows, venues, dates, booths, budgets, sales, or inventory
- No preset buying percentages or market price
- No fixed margin, readiness, expense, sell-through, or inventory metrics
- No numeric form placeholders that could be mistaken for user data
- Empty states guide the user to add their own information
- Calendar opens to the current month and displays only user-created events
- Card Shows uses a new clean local-storage version so legacy demo records do
  not reappear

The public marketing landing page remains unchanged and may continue to use
illustrative product-demo figures.
