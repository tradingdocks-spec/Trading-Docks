# Trading Docks v223 — Mana Pool generic panel removal

The generic API/platform-activation panel is now completely excluded whenever
Mana Pool is selected.

Mana Pool's own credential card now contains the permanent self-service
explanation:

- The seller's own Mana Pool API key connects the workspace
- No Trading Docks administrator activation is required
- The key remains encrypted and masked
- Import and replacement actions remain available

This removes the possibility of the generic administrator warning appearing
under Mana Pool.
