TRADING DOCKS FEEDBACK CENTER v64

1. Extract this ZIP directly into the root of the main Trading Docks repository.
2. Replace the matching files when prompted.
3. In Supabase, open SQL Editor and run:
   supabase/migrations/202607280008_feedback_center.sql
4. Commit and push the changes so Vercel redeploys the website.

The migration creates the private feedback queue, attachment records, a private
feedback-attachments storage bucket, owner-only administration permissions, and
the admin feedback queue function.

No new environment variables are required.
