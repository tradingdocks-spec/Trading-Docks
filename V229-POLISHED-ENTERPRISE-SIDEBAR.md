# Trading Docks v229 — Polished Enterprise Sidebar

## Navigation architecture
- Core, Commerce, Intelligence, Operations, and Workspace groupings
- Only one expandable section remains open at a time
- Expanded sections show four priority destinations
- Lower-frequency destinations move behind a clear View all action
- Active page uses a cyan left rail, soft blue gradient, and stronger type
- Parent expansion never competes visually with the selected child page

## Visual cleanup
- Removed card borders from standard navigation rows
- Standardized 18px primary icons and 16px child icons
- Increased whitespace between sections while tightening related child links
- Removed persistent focus-ring appearance from expansion buttons
- Added hidden scrollbars while preserving scrolling

## Footer
- Combined workspace identity, owner role, Admin Control Center, settings, sign out, and collapse controls into one footer card
- Removed the separate gold Admin Control Center block

## Collapsed mode
- Reduced desktop collapsed width to 76px
- Icon-only navigation with browser tooltips
- Compact account avatar and expand control
