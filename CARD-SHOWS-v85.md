# Trading Docks Card Shows v85

Card Shows is now a dedicated Seller-plan module.

## Included

- Card show overview with event readiness and metrics
- Event calendar and add-event workflow
- Singles and sealed-product buying calculator
- Separate saved buying percentages for singles and sealed
- Show inventory modeled as a temporary inventory location
- Fast show-sale entry and recent-sales ledger
- Event-level profit and operational reports
- Seller-plan access control with Store-plan inheritance
- Responsive desktop, tablet, and mobile layouts
- Device-local persistence for events, rates, and sales

## Install

Extract this ZIP into the repository folder containing `package.json`, allow matching files to be replaced, commit, push, and redeploy.

The current release provides a production-quality interactive module and saves Card Shows data in the signed-in user’s browser. A future persistence migration can move these records to Supabase for cross-device and employee sharing without changing the user interface.
