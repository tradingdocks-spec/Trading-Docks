# V291 — Deck Playtest Simulator

The Deck Vault Playtest tab now opens a functional tabletop-style simulator instead of falling through to Analytics.

Included:

- Randomized seven-card opening hands
- New-hand reshuffling and London mulligan tracking
- Play/draw selection
- Single-card draws and automatic next-turn draws
- Turn, library, hand, battlefield, graveyard, and exile counters
- Card movement between hand, battlefield, graveyard, and exile
- Commander held separately in the command zone
- Sideboard and maybeboard cards excluded from the shuffled library
- Responsive card layout using the deck's existing card images
- Empty-deck guidance and disabled draw controls when the library is empty

The Playtest renderer is connected to both maintained Deck Vault workspace variants.
