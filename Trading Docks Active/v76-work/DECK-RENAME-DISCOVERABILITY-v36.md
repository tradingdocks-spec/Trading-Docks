# Deck Rename Discoverability v36

- Every saved or imported deck card now has an always-visible **Rename** button.
- Rename no longer depends on hovering over a hidden icon or finding a three-dot menu.
- The existing rename dialog still updates the same saved deck record.
- The pencil control beside the title inside an opened deck remains available.
- Delete stays visually secondary and appears on hover or keyboard focus.
