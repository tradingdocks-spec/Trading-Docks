# V285 — Sealed Precon Price Comparison

Expanded Purchasing → Precon Breakdowns with a seven-source sealed-product comparison workspace.

## Sources included

- Stomping Grounds
- Amazon
- Walmart
- Gamers Guild AZ
- TCGplayer
- Mana Pool
- Cardsphere

## Workflow

- Opens a product-specific live search at each source
- Records item price, shipping, and availability for the exact listing reviewed
- Calculates delivered cost for every verified in-stock listing
- Identifies the lowest verified delivered price
- Applies the best price directly to the existing profit and ROI analysis
- Clearly identifies Cardsphere as a community-market reference when sealed inventory is unavailable

The interface does not fabricate or cache retailer prices. A quote is counted as verified only after the user records a live listing and marks it in stock. No database migration or new environment variable is required.
