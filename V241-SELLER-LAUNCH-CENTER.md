# Trading Docks v241 — Seller Launch Center

Introduces the first customer-readiness workflow for new Seller accounts.

## New route

`/dashboard/seller-launch`

## Guided setup

- Confirm Seller workspace
- Add or import inventory
- Validate CSV workflows
- Connect a marketplace
- Import and review an order
- Configure purchasing intelligence
- Create a customer
- Review seller automation

## Experience

- Required vs recommended setup steps
- Persistent browser-based checklist
- Seller launch score
- Recommended next action
- Core workflow readiness standard
- Mobile and desktop responsive layout
- Seller and Store permission gate
