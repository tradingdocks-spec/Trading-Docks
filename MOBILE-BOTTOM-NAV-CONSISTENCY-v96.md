# Mobile bottom navigation consistency

The shared mobile navigation now applies one visual style to Home, Inventory,
Decks, Settings, and All Menu.

- Identical 52 px touch-target height
- Identical 18 px icon size
- Identical 10 px semibold label typography and baseline
- Identical spacing, padding, inactive color, and pressed state
- All Menu receives the same active treatment while its drawer is open
- Long labels remain contained within their equal-width navigation cells

The complete production build passes all 72 application pages.
