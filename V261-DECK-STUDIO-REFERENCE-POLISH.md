# Trading Docks v261 — Deck Studio reference polish

This release brings the current Deck Studio closer to the polished reference
layout:

- Stronger DECK STUDIO title treatment
- Compact metric strip for cards, unique cards, missing cards, value, and power
- Tighter three-column application layout
- More refined Commander rail
- More compact Deck Construction Canvas
- Cleaner Deck Canvas table treatment
- Stronger pinned Live Inspector
- New bottom action dock with Undo, Redo, Trash, Duplicate, Move, Replace, Sort,
  and AI Optimize actions
- Preserves right-side hover inspection, external drops, trash, Undo, autosave,
  replacement, and inventory protection

No Supabase migration is required.
